# BiliFlow v3.10.0 Bilibili iOS 9.8.0 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add evidence-backed Bilibili iOS 9.8.0 filtering for asynchronous related-card reinjection and reviewed remaining commercial/UI containers while preserving CDN behavior, ordinary content, unknown protobuf bytes, and the non-empty home feed.

**Architecture:** Keep `src/bilibili-endpoints.js` as the matcher source of truth. Add an exact volatile `AIRelateAsync` row and reuse the existing field-preserving protobuf rewrite helpers rather than reconstructing messages. Add only reviewed JSON live endpoints and exact schema fields found in current public implementations; all new responses use the existing request guard and no-store normalization.

**Tech Stack:** Pure JavaScript compatible with Shadowrocket WebView, Node.js built-in test runner, protobuf wire-level rewrites, deterministic `scripts/build.mjs`, vinext Sites frontend.

```js
function transformViewUniteAsyncModule(input, config) {
  return rewriteProtoMessage(input, function (field, bytes) {
    if (field.fieldNumber !== 1 || field.wireType !== 2) return null;
    var nested = transformViewUniteModule(protoPayload(bytes, field), config);
    if (!nested.valid) return { invalid: true };
    if (nested.changed > 0 && nested.empty) {
      return { changed: nested.changed + 1, remove: true };
    }
    return nested.changed > 0 ? { changed: nested.changed, payload: nested.body } : null;
  });
}
```
