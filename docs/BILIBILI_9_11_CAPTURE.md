# Bilibili iOS 9.11.0 / 海外版 6.5.0 验收与抓包

目标版本：粉版 `id736536022` 9.11.0、海外版 `id1517062289` 6.5.0。
海外版不是东南亚 `id1548857482`；不要混用域名和接口假设。
当前交付 v3.12.0，真机状态：**均未验证**。

## 首轮配置

- 只启用 Enhanced 或 CDN Switcher 中一个，更新模块和脚本到 3.12.0。
- 使用配置路由。以 `DIRECT` 为基线，有大陆回国策略时再在同一网络单独对照。
- `CDN=auto`、`测速方式=cron`、`首页补齐6条=false`；不要用 blocking 做日常播放。
- 网络档案能自动区分 Wi-Fi/蜂窝；同一 Wi-Fi 切换代理策略后，手动换档案或重置令牌，
  因为脚本不能从 SSID 得知代理出口变更。无需开启媒体 CDN 的 MITM。

## 手机检查

| 页面/操作 | 核对项目 |
| --- | --- |
| 冷启动与首页刷新各 5 次 | 开屏广告、首页商业卡；不足六条立即显示；默认没有 X-BiliFlow-Refill 请求 |
| 首页补取开关开启再刷新 | 最多补取一次；超时只保留已有结果；不重复卡片、不恢复广告 |
| 普通视频起播、拖动、清晰度切换 | 主/备地址保持当前视频身份与完整签名；没有起播同步测速 |
| 连续播放 10 分钟 | 缓冲次数与累计缓冲时间，记录清晰度、是否后台下载、Wi-Fi/蜂窝 |
| 播放器下方、暂停、结束、异步推荐 | 广告、商品区和底部弹窗；普通推荐、字幕、章节仍可用 |
| 动态综合/视频/个人分页、搜索、评论 | 可以刷新分页；不把登录或真实服务端错误改成成功 |
| 番剧频道 | 商业横幅移除，普通剧集、TIP、分页和空白占位正常 |
| 海外版语言切换 | 翻译标题、字幕、动态和账号状态保留 |
| 后台 30 秒、5 分钟、30 分钟后恢复 | 新响应再次过滤；没有网络请求的内存页面另外标注 |

比较模块开/关时固定设备、网络、视频、清晰度，分开记录首帧等待、持续缓冲与页面
加载时间。不要把单个匿名 CDN 测速结果当作手机端改善百分比。

## 如仍有广告或加载失败

临时打开调试日志，记录 App 完整名称/build、模块版本、请求 host/path、HTTP 状态、
`Content-Type`、`grpc-encoding`、`grpc-status`、`x-bili-moss-engine-type`、UA 与
是否有 trailers，以及出现问题的页面和操作。6.5.0 真实 UA 未确认，不能只凭版本号
认定其仍使用 `bili-inter` 前缀。

对应的 JSON/RPC 响应需保留嵌套结构、字段编号和广告标记；先移除 Cookie、
Authorization、access_key、buvid、mid、设备标识、IP、完整签名媒体 URL 等个人数据。
不要分享账号凭据或完整代理配置。无法解码的新 RPC 先记录，不能猜字段号整段删除。

设计与公开来源见 [v3.12 审计](V3_12_AUDIT.md)。
