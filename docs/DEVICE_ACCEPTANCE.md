## 安装与更新

- [ ] raw 安装链接能够唤起 Shadowrocket 并下载模块。
- [ ] 模块信息页显示正确名称和版本。
- [ ] “编辑参数”显示全部参数，中文说明可读。
- [ ] `更新模块` 能从同一 raw 地址获取当前版本。
- [ ] 更新后用户设置的策略和开关仍保持预期值。
- [ ] HTTPS 解密主机只新增 README 列出的 Bilibili API，不含媒体 CDN。
- [ ] CA 描述文件已安装并完全信任；Bilibili 无证书警告。

## 路由

- [ ] Shadowrocket 首页“全局路由”为“配置”时规则生效。
- [ ] 中国大陆 `分流策略=DIRECT`：首页、视频、番剧、评论、弹幕、直播可用。
- [ ] 海外使用真实大陆回国策略：上述流量命中目标策略。
- [ ] 海外无回国策略、使用 `DIRECT`：不把地区版权限制误判为脚本故障。
- [ ] `PCDN策略` 与 `分流策略` 相同时不额外阻断窄 PCDN 域。
- [ ] `PCDN策略=REJECT` 时只观察到 `*pcdn*.biliapi.net` 命中拒绝。
- [ ] 模块没有添加宽泛 IP/CIDR 或 MCDN 全域拒绝。

## 广告与界面

- [ ] 开屏、首页推荐、Story、搜索、相关推荐、评论、PGC/Web 推荐和直播中，
      已知广告位按开关清理。
- [ ] 顶部“游戏中心”“新征程”按 `界面精简` 开关移除/恢复。
- [ ] 底部“＋/发布”“会员购”按 `界面精简` 开关移除/恢复。
- [ ] “我的”中已知营销/服务入口按 `界面精简` 开关移除/恢复。
- [ ] 首页、动态/关注、消息、个人中心等正常入口仍存在。
- [ ] 历史、收藏、下载、设置、消息和未读计数正常。
- [ ] `搜索推广=false` 时搜索推广恢复，其他广告开关不受影响。
- [ ] `直播带货=false` 时购物卡片恢复，其他广告开关不受影响。
- [ ] 未识别的新卡片不会导致整个列表清空。

## 账号、会员与付费保护

- [ ] 未登录状态可以正常登录、验证码和安全校验。
- [ ] 普通账号的真实会员状态没有变化。
- [ ] 大会员账号的真实会员状态、到期信息和权益没有变化。
- [ ] 已购买/已授权内容仍按账号真实权限播放。
- [ ] 未购买内容没有被伪造为已购买或可播放。
- [ ] 点赞、投币、收藏、分享、评论、弹幕和直播互动正常。
- [ ] 支付或购买流程未被模块脚本匹配；验收可停在付款确认前，避免真实消费。

## 点播 CDN

- [ ] 普通 UGC 视频起播、暂停、续播和拖动进度正常。
- [ ] DASH 视频与音频同时正常，无“有画面无声音”或反向情况。
- [ ] 切换清晰度、帧率/编码后仍正常，各表示没有复用错误缓存。
- [ ] 免费 PGC/番剧正常。
- [ ] 账号已合法购买/授权的 PGC/PUGV 内容正常。
- [ ] DURL/分段视频正常，分段顺序没有变化。
- [ ] 首次自动学习不会改写当前响应或主动断开播放。
- [ ] 间隔至少 10 分钟后第二次确认，后续播放地址才可能提升备用 URL。
- [ ] 提升备用 URL 后，原始主 URL 仍作为备用存在。
- [ ] 更换视频、清晰度、编码或音轨不会沿用上一个资源的选择。
- [ ] `网络档案` 不同的两组缓存互不命中。
- [ ] 缓存过期后的首次请求先使用原始响应，再重新验证。
- [ ] 固定主机模式仅在明确需要时测试，失败后可立即改回 `auto`/`off`。

## 直播

- [ ] 进入直播间和切换清晰度正常。
- [ ] HLS/FLV 等直播媒体仍使用服务端签名 host/path/query。
- [ ] 弹幕、礼物区、关注和房间互动正常。
- [ ] `直播带货=true/false` 只影响明确购物卡片。
- [ ] PCDN 拒绝如导致直播异常，可通过恢复策略立即修复。

## 故障开放与回滚

- [ ] `CDN=off` 后播放使用 Bilibili 原始地址。
- [ ] 四个广告/UI 开关全关后正常数据保持原样。
- [ ] 停用模块后 Bilibili 恢复原始网络行为。
- [ ] 其他 Bilibili 模块全部关闭时，当前模块能独立工作。
- [ ] 模拟无效参数、非 JSON 或损坏 gRPC 时没有崩溃/空白页面。
- [ ] 调试日志不含完整签名 URL、Cookie、token 或响应正文。
- [ ] 按 README 的回滚顺序可以恢复播放。
