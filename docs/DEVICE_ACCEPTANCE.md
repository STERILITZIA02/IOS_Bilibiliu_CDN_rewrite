## 安装与更新

- [ ] raw 安装链接能够唤起 Shadowrocket 并下载模块。
- [ ] CDN-only、Enhanced 两个固定 URL 均可独立安装。
- [ ] 历史 `Bilibili.CDN.sgmodule` 与 Enhanced 内容和版本一致。
- [ ] 模块信息页显示正确名称和版本。
- [ ] “编辑参数”显示全部参数，中文说明可读。
- [ ] 更新到 3.3.0 后可见 `首页推荐6个普通视频`、`测速方式` 与 `CDN 学习状态`，
      模块脚本 URL 含 `?v=3.3.0`，并包含 `Bilibili Enhance Fresh UI` 请求脚本。
- [ ] `更新模块` 能从同一 raw 地址获取当前版本。
- [ ] 更新后 `[Rule]` 与 `[Script]` 的远程 URL 带当前 `?v=` 版本键，脚本 URL
      页面不再引用上一版本键。
- [ ] 更新后用户设置的策略和开关仍保持预期值。
- [ ] CDN-only 中没有 `Bilibili Enhance` 脚本或 Enhanced 专属 MITM 主机。
- [ ] Enhanced 同时包含 CDN JSON/gRPC 与广告/UI JSON/gRPC 脚本。
- [ ] HTTPS 解密主机只新增 README 列出的 Bilibili API，不含媒体 CDN。
- [ ] CA 描述文件已安装并完全信任；Bilibili 无证书警告。

## BiliFlow 网站

- [ ] iPhone Safari 纵向布局无横向溢出，底部一键安装栏不遮挡最后一项。
- [ ] iPad Safari 纵向/横向布局均可读，双栏摘要与设置顺序合理。
- [ ] CDN-only 与 Enhanced 切换后，只显示该变体适用的选项。
- [ ] 首页、“我的服务”“更多服务”的开关表示“是否显示”，与模块隐藏参数相反映射正确。
- [ ] 关闭“界面逐项精简”后，摘要显示所有可配置入口实际保留，同时此前选择仍被记住。
- [ ] 刷新页面后，本机选择从 `localStorage` 恢复；清除网站数据后恢复仓库默认值。
- [ ] 复制的 `/module.sgmodule?...` URL 能返回 `text/plain` 模块并包含所选参数。
- [ ] 一键安装链接可唤起 Shadowrocket；随后从同一 URL 更新时保留所选参数。
- [ ] 未知参数、重复参数、越界数字、非法 CDN 主机和换行/结构注入返回 `400`。
- [ ] GitHub 最新目录不可用时只使用同一站点部署提交中的已审核目录/模块快照；
      在线与快照来源漂移、目录与模块不匹配或结构校验失败时返回 `502`。
- [ ] 页面无登录、Cookie 横幅、分析请求或第三方用户数据上报。

## 路由

- [ ] Shadowrocket 首页“全局路由”为“配置”时规则生效。
- [ ] 中国大陆 `分流策略=DIRECT`：首页、视频、番剧、评论、弹幕、直播可用。
- [ ] 海外使用真实大陆回国策略：上述流量命中目标策略。
- [ ] 海外无回国策略、使用 `DIRECT`：不把地区版权限制误判为脚本故障。
- [ ] `PCDN策略` 与 `分流策略` 相同时不额外阻断窄 PCDN 域。
- [ ] `PCDN策略=REJECT` 时只观察到 `*pcdn*.biliapi.net` 命中拒绝。
- [ ] 模块没有添加宽泛 IP/CIDR 或 MCDN 全域拒绝。

## 广告与界面

- [ ] 开屏、首页推荐、Story、搜索、相关推荐、评论、PGC/Web 推荐和直播中，
      已知广告位按开关清理。
- [ ] 完全退出 Bilibili 后第一次打开普通视频，播放器正下方的京东/下载/运营商
      营销条在页面可点击前即不出现；无需退出视频后第二次进入才消失。
- [ ] 普通视频播放后切到后台、保持暂停再回到前台，连续测试至少三次均不出现
      暂停广告；播放、拖动进度、画中画/后台切换和视频快照仍正常。
- [ ] 视频暂停后等待、切后台至少 30 分钟再恢复，以及从后台直接进入“我的”页，
      `PlayPause` 商业字段、`ViewEndPage` 广告/非普通 AV 卡、发布引导和大会员
      横幅均不重新出现；正常结束页普通 AV 和播放器状态仍存在。
- [ ] 冷启动、热启动、连续三次前后台切换后开屏 creative 不因 keep ID、本地缓存
      或 304 重新出现，且 App 没有因空响应结构持续重试 splash 接口。
- [ ] `广告过滤=true` 且 `推荐仅普通视频=true` 时，播放页下方只剩普通 UP/AV 视频；纪录片、综艺、
      番剧/国创/影视、直播、游戏、课程、活动、资源卡、广告、必火推荐和类型
      不明的卡片均不出现。
- [ ] `广告过滤=true` 且 `首页推荐6个普通视频=true` 时，首次进入首页以及每次
      下拉/自动刷新后，推荐流最多显示 6 条普通 AV；横幅、广告、小游戏/应用、
      纪录片、影视、综艺、番剧、直播、活动与未知卡片均不出现。
- [ ] 服务端本次提供 6 条以上合格 AV 时恰好保留前 6 条且顺序不变；不足 6 条时
      不复制旧卡、不出现占位卡，也不观察到脚本额外发起推荐接口请求。
- [ ] 连续刷新至少三次没有广告重新出现、重复请求循环或明显刷新延迟；Story
      只保留普通 `vertical_av`，`vertical_pgc` 与竖屏广告不出现。
- [ ] 外层关系类型伪装为 AV、但真实载荷为纪录片/番剧、直播、游戏或 CM 的卡片
      不出现；真实 `AV` 载荷的普通 UP 视频仍存在。
- [ ] `推荐仅普通视频=false` 时上述合法非视频推荐恢复，但明确广告在
      `广告过滤=true` 时仍不出现。
- [ ] 普通视频即使标题包含“广告”“纪录片”等词，也不会仅凭标题被误删；分类
      字段明确标记为纪录片/综艺等时才删除。
- [ ] 冷启动进入“我的”页以及从后台恢复后再次进入时，大会员横幅、会员区块和
      弹层均不出现；真实会员状态、到期时间、会员标签、钱包、订单、支付渠道与
      权益列表保持不变。
- [ ] 顶部“游戏中心”“新征程”按 `界面精简` 开关移除/恢复。
- [ ] 底部“＋/发布”“会员购”按 `界面精简` 开关移除/恢复。
- [ ] “我的”中已知营销/服务入口按 `界面精简` 开关移除/恢复。
- [ ] 每个首页、“我的服务”“更多服务”逐项开关只影响对应入口。
- [ ] `界面精简=false` 时所有逐项隐藏设置暂不执行，但重新开启后原选择恢复。
- [ ] 首页、动态/关注、消息、个人中心等正常入口仍存在。
- [ ] 历史、收藏、下载、设置、消息和未读计数正常。
- [ ] `搜索推广=false` 时搜索推广恢复，其他广告开关不受影响。
- [ ] `直播带货=false` 时购物卡片恢复，其他广告开关不受影响。
- [ ] 首页/推荐流未知卡片按 `首页推荐6个普通视频` 开关处理，播放页未知关系卡
      按 `推荐仅普通视频` 开关处理；其他页面的未知非目标卡片保持原样。

## 账号、会员与付费保护

- [ ] 未登录状态可以正常登录、验证码和安全校验。
- [ ] 普通账号的真实会员状态没有变化。
- [ ] 大会员账号的真实会员状态、到期信息和权益没有变化。
- [ ] 已购买/已授权内容仍按账号真实权限播放。
- [ ] 未购买内容没有被伪造为已购买或可播放。
- [ ] 点赞、投币、收藏、分享、评论、弹幕和直播互动正常。
- [ ] 支付或购买流程未被模块脚本匹配；验收可停在付款确认前，避免真实消费。

## 点播 CDN

- [ ] 普通 UGC 视频起播、暂停、续播和拖动进度正常。
- [ ] 短视频、竖屏视频、稍后再看、收藏/历史入口和连续播放均正常使用当前
      PlayerUnite/PlayURL 播放地址，不出现画面撕裂、错误音轨或异常重连。
- [ ] DASH 视频与音频同时正常，无“有画面无声音”或反向情况。
- [ ] 切换清晰度、帧率/编码后仍正常，各表示没有复用错误缓存。
- [ ] 免费 PGC/番剧正常。
- [ ] 账号已合法购买/授权的 PGC/PUGV 内容正常。
- [ ] PGC gateway `v1/v2` 与课程/cheese 播放入口均能解析压缩或未压缩 gRPC，
      无法解析时原始响应仍可播放。
- [ ] DURL/分段视频正常，分段顺序没有变化。
- [ ] 首次自动学习不会改写当前响应或主动断开播放。
- [ ] 默认 `测速方式=nonblocking` 时，无缓存的第一次 playurl 不等待两条 Range
      探测完成才起播；有缓存时在发起任何探测前立即使用已验证选择。
- [ ] 若本机在 `$done()` 后不继续运行异步回调，临时改为一次 `blocking` 能完成
      确定性学习；恢复 `nonblocking` 后首播仍不等待探测。
- [ ] `测速方式=off` 不发起 Range 请求，但继续复用未过期的已验证缓存。
- [ ] 间隔至少 10 分钟后第二次确认，后续播放地址才可能提升备用 URL。
- [ ] 主备样本的 Range 起止、总长度、实际长度、样本 hash 任一不一致，或出现
      内容压缩、跨对象重定向、HTML/JSON/XML/错误页时均不晋升备用线路。
- [ ] 提升备用 URL 后，原始主 URL 仍作为备用存在。
- [ ] 更换视频、清晰度、编码或音轨不会沿用上一个资源的选择。
- [ ] `网络档案` 不同的两组缓存互不命中。
- [ ] `网络档案=auto` 仅表现为共享档案，不会声称或表现为自动识别 Wi-Fi/蜂窝/
      SSID；需要隔离时手动使用两个档案名。
- [ ] 缓存过期后的首次请求先使用原始响应，再重新验证。
- [ ] `测速间隔=72` 的有效缓存不会被更短的隐藏上限提前失效。
- [ ] 更改 `CDN 学习状态` 令牌只清空一次学习状态；再次使用相同令牌不重复清空。
- [ ] 固定主机仅在目标完整 URL 已由当前同一媒体对象返回时提升；目标缺失、任一
      alias lane 缺失或签名不匹配时原样放行，可立即改回 `auto`/`off`。

## 直播

- [ ] 进入直播间和切换清晰度正常。
- [ ] HLS/FLV 等直播媒体仍使用服务端签名 host/path/query。
- [ ] 弹幕、礼物区、关注和房间互动正常。
- [ ] `直播带货=true/false` 只影响明确购物卡片。
- [ ] PCDN 拒绝如导致直播异常，可通过恢复策略立即修复。

## 故障开放与回滚

- [ ] `CDN=off` 后播放使用 Bilibili 原始地址。
- [ ] 七个核心广告/UI 开关全关后，广告、非视频推荐与界面响应保持原样。
- [ ] 所有逐项隐藏开关关闭后，已审核入口恢复且未知入口仍保留。
- [ ] 停用模块后 Bilibili 恢复原始网络行为。
- [ ] 其他 Bilibili 模块全部关闭时，当前模块能独立工作。
- [ ] 模拟无效参数、非 JSON 或损坏 gRPC 时没有崩溃/空白页面。
- [ ] 调试日志不含完整签名 URL、Cookie、token 或响应正文。
- [ ] 按 README 的回滚顺序可以恢复播放。
